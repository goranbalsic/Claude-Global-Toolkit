# Code of Conduct

## Standard

This project follows the [Contributor Covenant
v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion focused on the
technical question. Harassment, personal attacks, and demeaning language are not
acceptable in issues, pull requests, commit messages, or code.

## Practical notes for this project

- Critique the design, not the person. A rejected proposal is a design decision,
  not a judgement about the contributor.
- Say what you actually verified. Claiming a test passed when it was not run
  wastes reviewers' time and undermines the project's central rule.
- Reports of security issues get handled privately. See `SECURITY.md`.

## Enforcement

Report unacceptable behaviour to the maintainer at goranbalsic@gmail.com. Reports
are handled confidentially. Maintainers may edit, hide, or remove contributions
and may block accounts for repeated or severe violations.
