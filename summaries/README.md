# summaries/

Batch summaries, one file per completed batch, written using
`templates/handoff.md`, per the batching process in `HOW_TO_BUILD.md`.

Naming convention: `BATCH-<n>-<short-topic>.md`, e.g.
`BATCH-01-initial-toolkit-build.md`.

See `BATCH-01-initial-toolkit-build.md` for the summary of this repository's
initial build pass, and `BATCH-02-audit-verification-export.md` for the
final audit, Claude Code version verification, real-install confirmation,
and Markdown export batch.
